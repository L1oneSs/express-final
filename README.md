# Тихий список — Express и PostgreSQL

Автор: **Чирков Лев Сергеевич**, Moodle: **l1onesss**. Практическое задание от 24.10.2026. Проверка условий размещения: **14.11.2026**. HTTPS-адрес будет добавлен после публикации на Render; до этого проект нельзя считать полностью готовым к сдаче.

Приложение позволяет добавлять дела, редактировать названия, менять статус выполнения и удалять записи. Интерфейс работает на обычном HTML, CSS и JavaScript, адаптируется к телефону и поддерживает управление с клавиатуры. После ввода токена показывает логин и ФИО автора. Токен хранится только в памяти страницы, исчезает после выхода или перезагрузки и никогда не включается в исходники.

Выбран PostgreSQL в Supabase: есть постоянный бесплатный тариф и возможность независимого подключения преподавателя к той же базе. В отличие от временного гранта, бесплатный план не имеет заранее установленного срока окончания, но ограничен квотами и приостанавливается после недели неактивности. Перед проверкой необходимо убедиться, что проект активен. Timeweb требует оплаты ресурсов, а на проверенном Helios отсутствуют Node.js и npm в стандартном пути. Создание платных ресурсов не выполнялось.

Сервер разделён на конфигурацию, HTTP-маршруты и PostgreSQL-репозиторий. Express проверяет Bearer-токен до разбора JSON. Запросы к БД параметризованы; список всегда ограничен автором и выбранным runId. Кэш записей отсутствует: обновление страницы или кнопка «Обновить» загружает актуальные данные. Идентификатор, время создания и начальный статус задаются сервером через значения по умолчанию БД; ownerLogin берётся исключительно из конфигурации. Время возвращается строкой UTC ISO 8601.

Для запуска нужны Node.js 22 или новее, зависимости из lock-файла и заполненный локальный `.env`. Проверенные версии: Node.js **22.17.0**, Express **5.3.0**, PostgreSQL **17.11**. `.env.example` содержит только образцы. На существующем проекте схема уже применена; повторная инициализация не нужна. Для новой базы выполните инициализацию администратором, затем назначьте отдельные случайные пароли ролям по инструкции в `docs/deployment.md`.

Приложение подключается ролью `todo_app`, преподаватель — отдельной ролью `todo_reviewer`. Обе имеют только чтение, добавление, изменение и удаление учебной таблицы; RLS закрывает её для анонимных пользователей Supabase. У преподавателя нет доступа к пользователям Auth, изменению схемы и очистке таблицы через TRUNCATE. Соединение использует TLS с проверкой цепочки сертификатов и имени сервера; публичный CA лежит в `certs/`.

Персональное дело «Итоговая работа 24.10.2026: l1onesss» создано через API с runId `manual`. Автоматические проверки охватывают HTTP-контракт, браузерный CRUD, реальные изменения БД через независимое соединение, удаление с обеих сторон и сохранение после перезапуска. Тестовые записи удаляются после проверки. Секретные данные находятся только в игнорируемых `.env` и `.private/`; преподавателю передаются его отдельные реквизиты личным сообщением Moodle. В публичную тему прикладываются HTTPS-адрес, этот README и точный commit либо ZIP без секретов.

## Сопоставление полей

| Поле JSON | Столбец public.tasks | Тип PostgreSQL / правило |
| --- | --- | --- |
| id | id | uuid, PRIMARY KEY, gen_random_uuid() |
| ownerLogin | owner_login | text, логин из конфигурации сервера |
| title | title | text, trim, 1–200 символов |
| done | done | boolean, по умолчанию false |
| runId | run_id | text, 1–64 символа A–Z/a–z/0–9/_/- |
| createdAt | created_at | timestamptz, now(); JSON UTC ISO 8601 |

## Команды

```powershell
npm.cmd ci
Copy-Item .env.example .env # Только при первом запуске; заполните .env
npm.cmd run db:init        # Только новая БД; нужна DATABASE_ADMIN_URL
npm.cmd start
# В другом терминале:
npm.cmd run seed
npm.cmd test
npm.cmd run test:integration
npm.cmd run test:browser   # Windows: установленный Edge; Linux: npx playwright install chromium
```

Открыть локально: `http://127.0.0.1:3000`. Публикация и независимое подключение: [docs/deployment.md](docs/deployment.md). Результаты проверки: [docs/verification.md](docs/verification.md).
