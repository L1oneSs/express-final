## Совместимость расширения списков с PDF

`db/lists.sql` добавлен отдельной миграцией без изменения шести полей задач и обязательных маршрутов. Старый POST с любым валидным runId работает: invoker-триггер регистрирует список перед вставкой дела. Та же регистрация проверена при независимом INSERT преподавателя. Переименование меняет только name, runId остаётся стабильным. `GET /api/lists/:id/tasks/` возвращает метаданные списка с названием и отдельный массив прежних объектов дел. Исходный `GET /api/tasks/?runId=...` остаётся массивом без изменения структуры.

Токен преподавателя даёт роль reviewer в `/api/session/`, а `/api/author/` по-прежнему возвращает студента. Аватар с фиксированными инициалами, декоративные подписи и кнопки ручного открытия/обновления удалены. При входе преподавателя автор работы показан отдельно, в том числе на мобильном экране. Замечаний Supabase security advisors после миграции нет.

Успешная проверка TLS получена с официальным CA, без отключения rejectUnauthorized. Прямой адрес разрешается в IPv6; локальная сеть возвращает ENETUNREACH.

В PATH нет node/nodejs/npm. `psql --version` и сервер `pg`, база `studs`, показывают PostgreSQL 18.3. Проверен текущий пользователь s506308. `quota` не установлен, квота хранения не подтверждена.
